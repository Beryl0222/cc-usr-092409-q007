# 银龄多形态课程接续

本仓库保存该服务的领域资料、事件约定与连续学习档案实现，供业务团队在统一语义上继续建设。

## 已有内容

- `contracts/domain.schema.json`：领域事件的基础字段、聚合类型和事件名称。
- `data/`：可用于联调的中文样例记录。
- `src/validator.py`：校验事件信封的基础字段与已知类型。
- `src/intervals.py`：生效区间与时间线，任意时刻至多一条事实生效。
- `src/clock.py`：可注入时钟，超时释放名额等业务时间统一由此取得。
- `src/domain.py`：领域类型（授课形态、支持需求、缺席归因与各类记录）。
- `src/store.py`：追加式事件存储（内存 / JSONL 文件），支持完整重放。
- `src/service.py`：连续学习档案服务（事件溯源外观）。
- `tests/`：验证样例、区间语义与各业务流程。

## 业务约定

- 课程版本、报名资格、支持需求、授课形态与每次学习记录分别保存在生效区间上；后写入的记录优先，既往区间保留，教务员可解释"那段时间为什么这样安排"。
- 换班或换形态先评估教师资历、名额与支持资源，生成建议方案；学员确认后才迁移，确认时再复评一次；同班换形态不占用新名额。
- 已经完成的学习成果不可改写，也不因后续改班被覆盖；业务更正产生后继记录。
- 支持需求变化只影响未来场次，既往场次仍按当时需求评估。
- 安全限制只暂停指定授课形态的场次，其他可参加内容保留；暂停期间的缺席按安全暂停归因。
- 缺席按原因归因：场地调整、安全暂停、支持未落实、医嘱请假等均不计入主动退学统计，只有主动缺席计入。
- 候补按原申请时间排序，只推进支持条件可满足的申请；超时未确认的名额由注入时钟释放，释放后按原申请时间继续推进。
- 电话或线下签到重复上传只记一次（按上传标识幂等）；内容冲突两路都保留，交教务核对。
- 所有状态变化写入事件日志；重启后重放恢复，继续提醒、候补推进与阶段回顾。
- 涉及个人、机构或商业敏感信息时，调用方只读取完成职责所必需的字段。

## 本地检查

```bash
python3 -m unittest discover -s tests
```

## 测试与构建

测试命令：

```bash
python3 -m unittest discover -s tests
```

编译或构建命令：

```bash
python3 -m compileall -q src tests
```

上述命令均在单个 Linux 应用容器内执行，不需要另行启动外部服务。
