# 银龄多形态课程接续

本仓库保存该服务的领域资料、事件约定与连续学习档案的领域实现，供业务团队在统一语义上继续建设。

## 已有内容

- `contracts/domain.schema.json`：领域事件的基础字段、聚合类型和事件名称。
- `data/sample.json`：可用于联调的中文样例记录。
- `src/validator.py`：校验事件信封的基础字段，事件与聚合名称和契约保持一致。
- `src/continuity/`：连续学习档案领域实现：
  - `model.py`：课程版本、报名资格、支持需求、授课形态、学习记录均以生效区间 `[valid_from, valid_to)` 保存，更正只追加后继版本；
  - `service.py`：报名、换班/换形态（先核验教师资历、名额、支持资源，学员确认后才迁移）、支持需求调整（只影响未来场次）、安全限制（暂停对应形态活动，其余保留）、候补（按原申请时间与可满足条件推进，超时由注入时钟释放）、签到上传（重复只记一次，冲突交教务核对）、阶段回顾；
  - `clock.py`：可注入时钟，生产用系统时钟，测试用手动时钟；
  - `store.py`：JSONL 事件存储，重启后回放重建，并继续到期的提醒、候补与阶段回顾；
  - `explain.py`：教务解释视图，说明一段时间内学员为何被安排到某种授课形态、哪些支持已落实、缺席如何归因、学习目标怎样跨班接续。
- `tests/`：验证样例、基础约定与领域行为。

## 领域边界

当前资料围绕混合课程、教师资历和候补名额整理。事件一旦被接收，其标识、发生时间和版本不应被原地改写；业务更正应产生后继记录。已完成的学习成果不因后续改班被覆盖；缺席默认记为待归因，只有主动缺席计入退学评估。涉及个人、机构或商业敏感信息时，调用方只读取完成职责所必需的字段。

## 本地检查

```bash
python3 -m unittest discover -s tests
```

## 测试与构建

测试命令：

```bash
python3 -m unittest discover -s tests
```

编译或构建命令：

```bash
python3 -m compileall -q src tests
```

上述命令均在单个 Linux 应用容器内执行，不需要另行启动外部服务。
